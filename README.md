# Amazon Product Data Scraper

A Python web scraping project built with **Playwright** to collect product information from Amazon search results.

## Features

- Extract product titles
- Collect product prices
- Extract product ratings
- Collect product URLs
- Export data to CSV and Excel files

## Technologies Used

- Python
- Playwright
- Pandas
- CSV
- Excel

## Project Output

The scraper collected 16 product records in a test run.

| Field | Description |
|---|---|
| Title | Product name |
| Price | Product price |
| Rating | Product rating |
| Product URL | Clickable product link |

## Installation

```bash
pip install -r requirements.txt
```

## Usage

Run the Python scraper:

```bash
python amazon_scraper.py
```
